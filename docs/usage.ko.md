# AxSSH 빠른 사용 안내

이 안내서는 한국어 인터페이스의 기본 사용법을 설명합니다. 전체 기능은 [영어 안내서](usage.md)를 참고하세요.

## 언어

**설정 > 일반 > 언어 > 한국어**를 선택하세요. **시스템 설정 따르기**는 시스템 언어에 맞는 지원 번역을 선택합니다. 저장이 성공하면 모든 창에 적용됩니다.

언어 설정은 AxSSH 인터페이스에 적용됩니다. 터미널 출력, 직접 지정한 이름과 경로, 기술적인 오류 세부 정보는 원래 내용을 유지합니다.

## 연결

**새 서버**에서 SSH, Telnet 또는 직렬 포트를 선택하세요. SSH에서는 호스트와 사용자 이름을 입력하고 비밀번호, 개인 키 또는 SSH 에이전트를 선택합니다. **저장**은 설정을 저장하고 **저장 및 연결**은 저장 후 연결합니다.

알 수 없거나 변경된 SSH 호스트 키의 SHA-256 지문을 확인하고 명시적으로 신뢰를 승인하세요. Telnet은 암호화나 호스트 신원 확인을 제공하지 않습니다.

## 터미널과 파일

저장된 연결과 로컬 셸은 분할 영역 및 독립 창을 지원하는 터미널 탭으로 열립니다. SFTP는 별도 탭에서 로컬 및 원격 파일, 업로드, 다운로드, 이름 변경과 연결된 앱을 통한 외부 편집을 제공합니다.

설정과 단축키의 자세한 내용은 [전체 안내서](usage.md)를 참고하세요.
