# AxSSH 簡明使用指南

這份指南介紹繁體中文介面的基本操作。完整功能請參閱[英文指南](usage.md)或[簡體中文指南](usage.zh.md)。

## 介面語言

選擇 **設定 > 一般 > 語言 > 繁體中文**。**跟隨系統** 會依系統語言選擇已有譯文；zh-TW、zh-HK、zh-MO、zh-Hant 使用繁體中文。設定成功儲存後立即套用到所有視窗。

語言設定適用於 AxSSH 介面；終端機輸出、自訂名稱與路徑、技術性錯誤詳情保留原始內容。

## 建立連線

選擇 **新建伺服器**，再選 SSH、Telnet 或串列埠。SSH 需要主機位址、使用者名稱，以及密碼、私密金鑰或 SSH agent。**儲存** 儲存設定，**儲存並連線** 儲存後建立連線。

遇到未知或已變更的 SSH 主機金鑰，先核對 SHA-256 指紋，再明確確認信任。Telnet 不提供加密或主機身分驗證。

## 終端機與檔案

已儲存連線和本機 shell 在終端機分頁開啟，支援分割區域與獨立視窗。SFTP 使用專屬分頁瀏覽本機及遠端檔案，可上傳、下載、重新命名，並使用系統關聯程式進行外部編輯。

設定與快捷鍵詳情見[完整使用指南](usage.md)。
