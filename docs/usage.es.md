# Guía breve de AxSSH

Esta guía presenta la interfaz en español. La documentación completa está [en inglés](usage.md).

## Idioma

Seleccione **Ajustes > General > Idioma > Español**. **Seguir el sistema** elige la traducción disponible que coincide con el idioma del sistema. Los cambios se aplican a todas las ventanas tras guardarse correctamente.

El idioma se aplica a la interfaz de AxSSH. La salida del terminal, los nombres y rutas propios y los detalles técnicos de errores conservan su forma original.

## Conexión

Seleccione **Nuevo servidor** y elija SSH, Telnet o un puerto serie. Para SSH, indique el host y el usuario y elija contraseña, clave privada o agente SSH. **Guardar** guarda; **Guardar y conectar** guarda y conecta.

Verifique la huella SHA-256 de claves de host SSH desconocidas o modificadas y confirme explícitamente la confianza. Telnet no ofrece cifrado ni verificación de identidad del host.

## Terminal y archivos

Las conexiones guardadas y los shells locales se abren en pestañas de terminal con paneles divisibles y ventanas independientes. SFTP tiene pestañas propias para archivos locales y remotos, subidas, descargas, cambios de nombre y edición externa con la aplicación asociada.

Consulte ajustes y atajos en la [guía completa](usage.md).
