## 风险与阻塞

- 不设客户端文件大小、文件/目录数量、递归深度、路径/名称字符数和目录文本总量上限；目标服务器与操作系统自身约束仍会使个别条目失败，应用会逐项报告。
- SFTP 并发、分页、分块与协议请求超时仍保留；这些控制吞吐/内存和界面渲染节奏，不作为内容数量或文件大小门槛。
