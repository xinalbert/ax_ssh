## 风险与阻塞

- 暂停不得丢弃有副作用的进行中操作；在途请求有界推进，暂停保留临时数据，取消清理后再终态。
- 目录和全页暂停必须覆盖新子项；全部取消使旧批次失效，但不取消用户之后新建的任务。
- 批量操作通过单个有界命令提交，不能队列半满时只改一部分 UI。
- 本机仅验证 macOS ARM64，其他原生 CI 和 GUI/真实 SSH 生命周期仍需验收。
