# AxSSH quick guide — United Kingdom

This quick guide covers the British English interface. The [full usage guide](usage.md) documents all features.

## Interface language

Choose **Settings > General > Language > English (United Kingdom)**. **Follow system** selects this variant for en-GB systems. Other English regions retain the original English option. British display spelling includes colour, licence and behaviour.

Changes apply to all windows after saving succeeds. The language setting applies to the AxSSH interface; terminal output, your own names and paths, and technical error details retain their original form.

## Connection

Choose **New Server**, then SSH, Telnet or Serial. For SSH, enter the host and username and select a password, private key or SSH agent. **Save** saves the configuration; **Save & connect** saves and connects.

Check the SHA-256 fingerprint of an unknown or changed SSH host key and explicitly confirm trust. Telnet provides neither encryption nor host identity verification.

## Terminal and files

Saved connections and local shells open terminal tabs with split panes and detached windows. SFTP uses separate tabs for local and remote files, uploads, downloads, renaming and external editing through the associated application.

See the [full guide](usage.md) for settings and keyboard shortcuts.
