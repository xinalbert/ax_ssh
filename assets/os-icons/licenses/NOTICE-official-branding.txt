Copyright and trademarks remain with their respective publishers. These original files were downloaded for identification and selection in AxSSH.
This source group has no common copyright license. A source link or a software repository license is not, by itself, an explicit license for every brand asset.
Where the inspected source does not specify an asset copyright license, the manifest records asset_license_status as not-explicitly-stated rather than assigning MIT, CC0 or the repository code license.
